## 1. ชุดสี A+ (ตัวแปร CSS)

ไล่ทแยงมุม **ชมพู ↖ → มิ้นต์ ↘** ทุกส่วน · พื้นเรียบ · ตรงกลางการไล่ใช้ขาวชุดพยาบาล

| ตัวแปร | ค่า | ใช้กับ |
|---|---|---|
| `--r-bg` | `#120d16` | พื้นทั้งหน้า |
| `--r-surface` | `rgba(255,255,255,.025)` + อมสีทแยง | การ์ด |
| `--r-pri` | `#f2437d` | ปุ่ม · หัวข้อสำคัญ · ลิงก์ |
| `--r-pri-hover` | `#ff4f8b` | ปุ่มตอนชี้ |
| `--r-pri-active` | `#d93a6e` | ปุ่มตอนกด |
| `--r-on-pri` | `#2a0414` | ตัวหนังสือบนปุ่มชมพู |
| `--r-acc` | `#22d6bf` | หัวข้อเล็กเหนือชื่อส่วน · จุดออนไลน์ · วงโฟกัส |
| `--r-nurse` | `#fff2f0` | สีกลางของการไล่ |
| `--r-text` | `#fff5f7` | ตัวหนังสือหลัก |
| `--r-text-2` | `#f3b8c4` | ตัวหนังสือรอง |
| `--r-text-3` | `rgba(243,184,196,.72)` | คำอธิบาย · วันที่ |
| `--r-line` | `rgba(255,255,255,.08)` | เส้นขอบการ์ด |

**สถานะปุ่มหลัก:** ปกติ `--r-pri` · ชี้ `--r-pri-hover` + เงาชมพู · กด `--r-pri-active` · โฟกัส `outline: 2px solid var(--r-acc); outline-offset: 3px` · ใช้ไม่ได้ พื้น `rgba(255,255,255,.08)` ตัวหนังสือ 38%

**คอนทราสต์ (ผ่าน WCAG AA ทั้งหมด):** `#fff5f7` 17.9 · `#f3b8c4` บนการ์ด 10.2 · ชมพูจาง 72% บนการ์ด 5.9 · ชมพู `#f2437d` บนการ์ด 4.8 · มิ้นต์บนการ์ด 9.3 · ตัวหนังสือบนปุ่ม 5.2

**แสงตามมุม (ต่อส่วน):**
- ทั่วไป: ชมพู 7% มุมซ้ายบน · มิ้นต์ 10% มุมขวาล่าง · วงรี 55% × 60% จางที่ 72%
- ส่วนเด่น (Hero · สมาชิก · ติดตาม): ชมพู 12% · มิ้นต์ 14% · Hero แสงชมพู 36% / มิ้นต์ 30%
- มือถือ: วงรี 110% × 50%
- การ์ด: `linear-gradient(135deg, ชมพู 7%, transparent 58%), linear-gradient(315deg, มิ้นต์ 8%, transparent 58%)`
